# SaaS 专项检查清单

逐项回答「涉及 / 不涉及 / 无法确认」，涉及项必须给证据。

## A. 多租户

- [ ] 新增 SQL 是否都带租户条件，或走统一拦截器
- [ ] 新增缓存 key 是否含租户维度
- [ ] 异步任务是否显式传递并恢复租户上下文
- [ ] MQ 消费是否从消息恢复租户
- [ ] 批量操作是否可能跨租户
- [ ] 特殊租户白名单/例外是否被新逻辑绕过
- [ ] 导出/下载是否按租户过滤

## B. 存量兼容

- [ ] 默认配置与未配置时行为
- [ ] 历史状态机是否允许旧状态
- [ ] 老接口字段与错误码是否保持
- [ ] 内部服务调用方是否兼容
- [ ] 特殊租户定制分支是否保留
- [ ] 兼容代码的退出条件与时间点

## C. 数据库

- [ ] 表结构变更与 DDL 影响
- [ ] 索引与查询计划
- [ ] 数据回填范围与耗时
- [ ] 新旧版本双写/双读
- [ ] 迁移顺序与回滚
- [ ] 不可逆操作清单

## D. 权限

- [ ] 新增权限点与默认角色
- [ ] 越权风险（水平/垂直）
- [ ] 后台管理与开放接口
- [ ] 数据导出与下载
- [ ] 审计覆盖

## E. 计费与权益

- [ ] 计费口径
- [ ] 权益快照
- [ ] 套餐限制
- [ ] 历史账单
- [ ] 对账与补账

## F. 消息与异步

- [ ] 契约字段兼容
- [ ] 生产/消费顺序
- [ ] 幂等键
- [ ] 重试与死信
- [ ] 历史消息兼容
- [ ] 消息堆积与降级

## G. 可观测性

- [ ] 业务日志字段
- [ ] 指标与阈值
- [ ] Trace 埋点
- [ ] 审计字段
- [ ] 告警接收人

## H. 风险分级

| 等级 | 判定条件（满足其一） |
| --- | --- |
| BLOCKER | 跨租户数据可见/写入、不可逆数据删除、权限绕过、资金错账 |
| HIGH | 数据写路径变更、权限点变更、对外契约变更、动态配置控制主流程、特殊租户定制 |
| MEDIUM | 间接依赖、Job、缓存、配置读取、只读表、异步链路 |
| LOW | 边缘引用、仅日志/监控 |
| INFO | 仅参考 |

分级说明必须包含：影响对象、触发条件、证据。
