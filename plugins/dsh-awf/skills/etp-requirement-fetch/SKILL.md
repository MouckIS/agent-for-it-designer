# 需求获取（etp-requirement-fetch）

状态：**占位，待实现**。本文件只固定 A1 依赖的最小输出，其余由实现决定。

## 何时使用

A1 需求获取阶段开始时读取；由 A1 根据 `us_source`（US 标识或链接）调用。

## 输入

- US 标识或链接（必填）
- 是否包含评论、附件、图片（可选）

## 输出（最小契约）

- 正文分块：文本 + 原文位置（章节号或锚点）
- 附件与图片：引用 + 可读文本。图片默认交给调用方用多模态直接识读，本 Skill 只需把原图落到 `01-source/assets/` 并给出每条 `ASSET-NNN` 的路径与原文件名；只有调用方模型无视觉能力时才降级 OCR，且降级结果必须标注 `engine`（如 `tesseract`）与置信度
- 外部参考资料：链接 + 摘要
- 来源元信息：`source_url`、`fetched_at`、`content_hash`

## 约束

- 取不到的内容返回明确缺口，不得返回空内容让下游猜。
- 不得用模型常识补全平台未提供的内容。
- 输出必须可定位到原文，供 A1 做前后端归属判断。
