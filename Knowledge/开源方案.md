### 一、企业级代码搜索/索引平台（团队级、跨仓库）
- Sourcegraph	业界标杆，基于 Zoekt 三元组索引，支持 regex/符号/跨仓库/历史 diff 搜索，Deep Search 支持自然语言提问，MCP 暴露给 Agent，SCIP 提供编译级精度导航
- Greptile	对代码库建 AST 图谱（函数、依赖、调用关系），主打 AI PR Review，被 22,000+ 团队使用，支持自托管（含离线）
- Augment Code (Context Engine)	托管语义索引，毫秒级同步，通过 MCP 接入 Claude Code、Cursor 等
- GitHub Copilot 仓库索引	如果代码在 GitHub 上，自带语义索引，秒级更新

### 二、开源/自建搜索引擎（免费、可嵌入自有平台）
- Zoekt（Apache 2.0）：Sourcegraph 维护的三元组索引引擎，实测 6 秒索引完 kubernetes 全库（31,300 文件），正则查询 193ms，适合做内部搜索底座。
- OpenGrok（CDDL）：老牌源码浏览+交叉引用引擎，Java 技术栈大库常用。
- Sourcebot：基于 Zoekt fork 的自托管方案，支持 GitHub/GitLab 多源索引、Ask 问答带引用；注意是 FSL 1.1 协议（2 年后转 Apache 2.0），基础版免费。
- 已淘汰的：bloop（2025 年 1 月归档）、Continue（2.0.0 后仓库只读）。

### 三、本地代码知识图谱 + MCP（给 AI Agent 用，当前最热）
- codebase-memory-mcp（约 38k stars）：C 写的本地持久化代码知识图谱，17 个 MCP 工具。
- GitNexus（约 45k stars）：纯浏览器端运行的零服务器代码图谱。
- CodeGraph / Serena / Synapse MCP：本地符号+调用图，Serena 走语言服务器协议，精度最高（符号级导航、重构）。
- Graphify / CodeGraph / CocoIndex：tree-sitter 解析建 typed graph（节点带 EXTRACTED/INFERRED/AMBIGUOUS 标记），或 AST 感知的增量语义索引（仅变更文件重新 embedding）。

### 四、Agent 内置/轻量方案
- Cursor：现在不再存 embedding，改用本地 Instant Grep 正则索引 + Explore 子代理。
- Claude Code：无索引，agentic grep 现场搜，免维护但费 token。
- Aider repo map：tree-sitter 建符号图并按 token 预算裁剪，适合会话级上下文。
- Repomix：把仓库打包成单个文件喂给 LLM，一次性场景用。

### 五、代码 Wiki / 文档生成类
- DeepWiki（Cognition）：托管 AI wiki，适合公开仓库快速读懂。
- repowise：本地跑，从代码图谱生成 wiki + git 历史 + 责任人 + 风险热点，10 个 MCP 工具。
